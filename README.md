# OMR রিডার PWA

কোনো সার্ভার-কোড লাগে না — শুধু স্ট্যাটিক ফাইল। PWA ও ক্যামেরার জন্য **HTTPS** (বা localhost) বাধ্যতামূলক।

## ইনস্টল/হোস্ট
- দ্রুত টেস্ট (পিসিতে): `python -m http.server 8080` → http://localhost:8080
- ফোনে ব্যবহার: ফোল্ডারটি Netlify Drop (app.netlify.com/drop), Cloudflare Pages বা GitHub Pages-এ আপলোড করুন → পাওয়া HTTPS লিংক ফোনের Chrome/Safari-তে খুলুন → "Add to Home screen / Install"।
- প্রথমবার লোডের পর (~14MB) অফলাইনেও চলে। Gemini শুধু ইন্টারনেটে কাজ করে।

## Gemini Key
সেটিংস ট্যাবে বসান (aistudio.google.com/apikey)। key কেবল ওই ডিভাইসের localStorage-এ থাকে এবং সরাসরি Google-এ যায়।
> সতর্কতা: ব্রাউজার থেকে সরাসরি কল হয়, তাই key নিজের ডিভাইসেই ব্যবহার করুন, অন্যের সাথে শেয়ার করা সাইটে নয়।

কোড আপডেট দিলে `sw.js`-এর `CACHE` নাম (omr-v1 → omr-v2) বদলাবেন।

## শিক্ষার্থী তালিকা
"উত্তর" ট্যাবে Excel/CSV আপলোড করুন (কলাম: নাম, শ্রেণি, রোল, গ্রুপ; হেডার থাকলে বাংলা/ইংরেজি দুটোই চলে, না থাকলে এই ক্রমে ধরা হয়)।
স্ক্যানের পর শিটের রোল-বাবল (না মিললে হাতের লেখা রোল) দিয়ে তালিকা থেকে নাম/শ্রেণি/গ্রুপ নিজে বসে। ফলাফল পেজে ড্রপডাউন থেকেও বাছা যায়।

## ম্যানুয়াল সংশোধন
- শিটের ছবিতে কোনো বৃত্তে ট্যাপ/ক্লিক করলে সেটি উত্তর হয়, আবার চাপলে মুছে যায়।
- "গ্রিড সরান" চালু করে ছবি টেনে নীল বৃত্তগুলো ছাপা বৃত্তের ওপর মেলান; ছাড়লে আবার পড়া হয় এবং অবস্থানটি পরের স্ক্যানের জন্যও সংরক্ষিত থাকে ("গ্রিড রিসেট" দিয়ে ফেরত)।
